# Sports Intelligence Terminal (SIT) - MVP

Персональний термінал спортивної аналітики з AI-акаунтом, який робить віртуальні (paper) ставки.
Усі матчі, коефіцієнти, новини та статистика в цій версії - згенеровані демо-дані.

## Структура файлів

```
index.html   розмітка-оболонка, підключення шрифту та скриптів (порядок важливий)
styles.css   дизайн-система: токени кольорів, темна/світла тема, адаптивність
data.js      шар даних: провайдери (sports / odds / news) + детермінований генератор демо-даних
engine.js    аналітичний рушій: фактори моделі, впевненість, ризики, рішення AI, пост-матч аналіз, LLM-хук
app.js       ядро: appState, localStorage, AI-акаунт, розрахунок ставок, статистика, графіки, UI-компоненти, роутер
views.js     сторінки (Dashboard, Scanner, Match, Opportunities, Live, News, Analytics, AI Analyst, AI Journal, Bet Journal, Settings)
```

## Запуск локально

Варіант 1: відкрити `index.html` подвійним кліком.

Варіант 2 (рекомендовано): локальний сервер у папці проєкту:

```
python3 -m http.server 8000
```

і відкрити http://localhost:8000

Перший запуск генерує 60 днів історії AI (кілька секунд), далі все зберігається в localStorage.

## GitHub Pages

1. Створити репозиторій, покласти всі 6 файлів у корінь.
2. Settings > Pages > Source: Deploy from a branch, гілка `main`, папка `/ (root)`.
3. Через 1-2 хвилини сайт буде на `https://<username>.github.io/<repo>/`.

## Де підключати реальні дані

- Спортивні дані, коефіцієнти, новини: `data.js`, розділ `PROVIDER CONTRACT` унизу файлу.
  Написати об'єкт з тими ж методами і присвоїти в `SIT.providers.sports / odds / news`.
  `app.js` і `views.js` змінювати не треба. Використовуйте ліцензовані API та умови сайтів, скрейпери не включені.
- LLM: `engine.js`, об'єкт `SIT.Engine.llm` (`enabled`, `explain(match, analysis)`).
  Ключі API не можна тримати у фронтенді: робіть виклик через свій бекенд/проксі.
- Модель: функції `calculate*()` і `analyzeMatch()` у `engine.js`, пороги та профілі ризику в `CONFIG`.

## Де змінювати демо

- Стартовий банкрол AI: Settings у застосунку, або `defaultState()` в `app.js` (`ai.startingBankroll`).
- Ваш стартовий банкрол: там само (`user.startingBankroll`).
- Ліги, команди, години матчів: масив `LEAGUES` у `data.js`.
- Довжина історії: `HISTORY_DAYS` в `app.js`.
- Повне скидання: Settings > Reset all data.

Імена гравців, тенісистів і бійців вигадані. Назви клубів реальні, але травми, склади й новини згенеровані.
