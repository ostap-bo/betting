# SIT, футбольна аналітика

Матчі дня й аналітика AI: що варто розглянути, що нейтрально, а що краще оминути.

## Файли

- `index.html`: сторінка
- `styles.css`: вигляд
- `app.js`: показ матчів і аналізу
- `matches.js`: матчі дня та аналітика (цей файл оновлюється щодня)

## Як оновити матчі

1. Напишіть Claude: «онови матчі на сьогодні».
2. Завантажте новий `matches.js`.
3. У репозиторії відкрийте `matches.js`, натисніть три крапки, потім Delete file і Commit changes.
4. Add file, Upload files, перетягніть новий `matches.js`, Commit changes.
5. Через хвилину оновіть сайт.
