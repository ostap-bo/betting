# SIT, спортивна аналітика (демо)

Персональний термінал аналітики для футболу, тенісу та кіберспорту.
Біла тема, синій акцент, усе українською. Працює без сервера: достатньо відкрити `index.html`.

## Що всередині

| Файл | Що робить |
|---|---|
| `index.html` | Сторінка, яка підключає все інше |
| `styles.css` | Зовнішній вигляд |
| `data.js` | Демо-матчі, коефіцієнти, новини |
| `model.js` | Модель: фактори, впевненість, ризики, рішення AI |
| `app.js` | Збереження даних, ставки, сповіщення, навігація |
| `views.js` | Сторінки: Головна, Матчі, Можливості, Наживо, AI-аналітик, Новини, Кабінет |

## Як опублікувати на GitHub Pages

1. Завантажте всі файли в корінь репозиторію (Add file, Upload files, Commit changes).
2. Settings, Pages, Branch: `main`, папка `/ (root)`, Save.
3. Через 1-2 хвилини сайт буде за адресою `https://ваш-логін.github.io/назва-репозиторію/`.

## Важливо

- Усі матчі, коефіцієнти, новини та імена гравців згенеровані. Ставки паперові, гроші віртуальні.
- Дані кабінету зберігаються лише у браузері (localStorage). Інший браузер або телефон матиме свій окремий кабінет.
- Щоб почати з нуля: Кабінет, Налаштування, Скинути все.

## Для подальшої розробки

- Реальні дані підключаються в `data.js` (об'єкт `SIT.providers` і функції `SIT.Data`).
- Модель і місце для LLM: `model.js` (`SIT.Model.llm`). API-ключі не можна зберігати у фронтенді.
- Довжина демо-історії AI: `HISTORY_DAYS` в `app.js`.
